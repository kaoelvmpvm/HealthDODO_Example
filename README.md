# 健促 AI 健多多｜示範案例資料站

供健康促進研習參與者使用的**七大議題示範資料選擇器**，可取得「示範國中」的**實作區虛擬校情**或**精進區虛擬成果**，一鍵複製後貼入該議題的健多多 GPTs。

## 功能

- 七大議題：視力保健、口腔保健、全民健保、健康體位、菸檳防制、全面性教育、正向心理健康促進。
- 兩種固定資料類型：實作區（虛擬校情）及精進區（虛擬成果），共 **14 份預設案例**。
- 每份案例均可預覽、**一鍵複製**、下載為 TXT。
- 依所選議題提供對應健多多 GPTs 的「開啟健多多」連結。
- 手機與桌面均可使用，不需登入，也不會將資料傳送到伺服器。
- URL 支援 `?topic=vision&mode=school` 分享特定議題與區域。

## 開啟網站

部署 GitHub Pages 後，預期網址為：

`https://kaoelvmpvm.github.io/HealthDODO_Example/`

此網址須在 GitHub Pages 啟用完成後才能實際使用；**僅有程式碼推送並不代表 Pages 已啟用**。

### GitHub Pages 首次部署

1. 進入本儲存庫的 **Settings → Pages**。
2. 在 **Build and deployment** 下，將 **Source** 設為 **Deploy from a branch**。
3. 選取 **main** 分支與 **/(root)** 資料夾，按 **Save**。
4. 待 GitHub Pages 建置完成後，回到 Pages 畫面確認公開網址。

本網站為純靜態 HTML/CSS/JavaScript，不需要伺服器、API Key 或額外框架。

## 案例設計原則

- 虛構學校統一為 **示範國中**，普通班30班、學生840人、教師65人，採 **114學年度**背景。
- 每個議題各有一份校情與一份成果，兩者以**相同初始指標**對應。
- 結果包含**達標與未達標**項目，以支援成果評讀與精進，而不是只有正面績效。
- 模擬問卷為學年度初與學年度末各300份的**不同時間點樣本**。未進行個人配對，也無對照組，**不得宣稱觀察到的百分比差異是方案造成的效果**。
- 健保、菸檳、全面性教育、心理健康等議題涉及法規、醫療或個別轉介時，仍須核對主管機關最新資訊與真實學校程序。
- 不涉及真實個資；所有統計、活動、經費、回饋均為虛構。
- 建議先選議題及區域、按下「一鍵複製完整資料」，再「開啟健多多」，於對應區域貼上案例。

## 專案結構

```text
index.html   網站主要結構
styles.css   桌面與手機響應式樣式
data.js      七大議題預設案例、指標及七個 GPTs 網址
app.js       議題切換、案例組裝、複製、下載、外部連結
README.md    專案與部署說明
```

## 維護指引

調整某議題的示範數值、活動、說明或 GPTs 連結：編輯 `data.js` 的對應議題物件，不需改動其他程式碼。若修改指標，請同時檢查該議題的校情、成果與達標門檻是否一致。

**資料用途：** 僅供教學、研習、操作練習。不得視為真實學校健康促進計畫或研究資料。
